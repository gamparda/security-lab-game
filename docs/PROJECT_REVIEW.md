# 코드 구조

| 파일 | 역할 |
| --- | --- |
| `src/missions.js` | 미션, 단서, 힌트, 해설 |
| `src/engine.js` | 명령 해석, 상태 변경, 완료 판정, 해시 |
| `src/storage.js` | 진행 저장·복원·검사 |
| `src/app.js` | 화면과 입력 |
| `src/bootstrap.js` | CSS·게임 준비 확인 |
| `run.py` | 게임 파일 전용 로컬 서버 |
| `launcher.py` | EXE 실행창과 서버 시작 |
| `scripts/package.py` | Python·게임 파일을 EXE로 패키징 |

HTML·CSS·JavaScript 구조를 유지합니다. 미션 추가 전 명령·단서 정의와 저장 버전 처리를 정리합니다. 다음 작업은 [ROADMAP.md](ROADMAP.md)에 있습니다.

## 개선 우선순위

| 순서 | 확인한 문제 | 다음 수정 |
| --- | --- | --- |
| 1 | 두 탭에서 플레이하면 오래된 탭의 저장이 최신 진행을 덮어씀. 튜토리얼 완료 후 다른 탭에서 힌트를 누르면 저장 미션이 1에서 0으로 돌아가는 것을 재현. | 저장 개정 번호·충돌 안내·다른 탭 갱신 감지. |
| 2 | `bootstrap.js` 요청 자체가 실패하면 60초 뒤에도 로딩 중이고 재시도 버튼이 숨겨져 있음. 브라우저에서 재현. | 시작 스크립트 로드 실패에도 제한 시간과 복구 수단 제공. |
| 3 | 다른 실행창이나 프로그램이 기본 포트를 사용하면 접속 포트가 바뀌어 기존 진행이 보이지 않음. | 단일 인스턴스 실행과 진행 내보내기·가져오기. |
| 4 | 저장 형식이 맞지 않으면 원본 저장을 삭제하고 초기화함. | 초기화 전 백업과 저장 버전 변환. |
| 5 | 미션 번호·개수·단서·명령 정의가 엔진·저장·화면에 나뉘어 고정됨. | 미션 ID와 정의를 기준으로 공통화한 뒤 미션 추가. |

재현은 Chromium에서 확인했습니다. 이번 릴리즈는 배포 파일을 변경하며, 위 게임 수정은 다음 작업입니다.
