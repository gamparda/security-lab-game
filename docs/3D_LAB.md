# 3D Security Lab v0.3.0

데스크톱의 기본 화면은 Blender에서 제작한 3D 실습실이다. 기존 터미널, 방어 설정, 파일 비교, 조사 노트는 실습실 안에서 여는 도구 창으로 유지한다. 모바일과 WebGL 사용이 어려운 환경에서는 2D 화면으로 진행할 수 있다.

## 실행과 조작

Windows: `SecurityLab.exe`를 실행하고 실행창을 플레이 동안 유지한다. Python, Node.js, Blender 설치는 필요 없다. Chrome 또는 Edge의 하드웨어 가속을 권장한다.

소스: `python run.py`를 실행한 뒤 `http://localhost:5173`을 연다. 개발 중 즉시 변경 반영이 필요하면 `npm run dev`를 사용한다. Python 서버는 시작 시 허용된 리소스를 메모리에 보관하므로 파일 변경 후 다시 시작한다.

탐색 시작을 누른 뒤 WASD로 걷고 마우스로 시점을 바꾼다. Shift는 달리기, E는 가까운 장비나 문 조작, Esc는 일시정지다. 도구 창을 닫은 뒤에는 탐색 시작을 다시 눌러 마우스를 잠근다. 출입구로 돌아가기는 위치만 초기화한다. 게임 진행 초기화는 기존 확인 대화상자를 사용한다.

## 공간과 모델

본 실습실은 24 × 20 m, 입구 전실을 포함한 전체는 24 × 23 m다. 천장 높이는 약 3.4 m, 플레이어 몸 높이는 1.8 m, 눈높이는 1.65 m다. 출입문은 폭 1.28 m, 높이 2.3 m로 제작했다. 책상 높이 0.77 m, 서버랙 높이 2.2 m, 의자 좌판 높이 0.47 m를 기준으로 한다.

실습실에는 운영 PC 구역, 유리 칸막이 서버실, 자료 보관실이 있다. 서버랙 6개에는 장착 레일, 10단 모듈, 손잡이, 상태등과 패치 케이블을 넣었다. 라우터·스위치·방화벽, 모니터, 키보드, PC 본체, 책상, 바퀴와 팔걸이가 있는 의자, 서랍 보관함, 화이트보드, 천장 패널, 조명, 케이블 트레이, 창틀, 안전선과 소화기 형상을 포함한다. 반복 서버랙과 의자는 같은 Mesh를 공유한다.

`assets/models/security_lab.glb`는 실제 Blender 5.2.2 LTS에서 내보낸 자급형 GLB다. 통계는 같은 위치의 `security_lab.json`에 기록한다. Blender 소스는 별도 전달한 `Security_Lab_Source.blend`이며, 제작 스크립트는 `scripts/build_security_lab.py`다.

```text
blender --background --python scripts/build_security_lab.py -- assets/models/security_lab.glb Security_Lab_Source.blend
```

새 장면에만 오브젝트를 추가하고 기존 Blender 장면을 삭제하지 않는다. 내보내기는 현재 새 장면으로 제한한다. 재질은 무광 도장, 금속, 라미네이트, 반투명 유리, 발광 상태등·스크린과 Poly Haven 콘크리트로 구성했다. 바닥은 직접 UV로 4 m 반복 크기를 설정하고 디퓨즈·거칠기·노멀 1K 텍스처를 묶었다. 상태 화면은 자체 제작 512 px 텍스처다. 런타임 외부 다운로드는 없다.

## 상호작용과 연결

| 오브젝트 | 열리는 기존 도구 |
| --- | --- |
| INTERACT_ServerRack | 가상 터미널 |
| INTERACT_AdminPC | 준비 미션은 터미널, 이후 미션은 방어 설정 |
| INTERACT_Router | 방어 설정 |
| INTERACT_FileCabinet | 파일 비교 |
| INTERACT_Whiteboard | 조사 노트와 기존 힌트 버튼 |

화면 중앙에서 2.65 m 이내의 가장 가까운 표면을 Raycast한다. 벽 뒤 장비는 선택되지 않는다. 문을 제외한 상호작용은 기존 화면을 열기만 한다. 명령 자동 실행, 단서 지급, 점수 지급 또는 검증 생략은 없다.

`src/labbridge.js`는 미션 ID·제목·단계·점수 등의 읽기 전용 상태와 도구 열기 요청만 전달한다. `src/app.js`의 기존 이벤트가 실제 조작을 처리하고 최신 main의 `engine.js`, `missions.js`, `storage.js`를 그대로 사용한다. 미션 ID로 기록하는 v2 저장, v1 진행 변환과 원본 백업, 다른 탭의 오래된 저장 차단, 진행 내보내기·가져오기를 유지하며 보기 방식은 별도 키에 저장한다. 3D 도구 창에서도 가져오기와 초기화 대화상자의 키보드 조작을 유지한다.

## 충돌과 문

`COLLIDER_*` 박스 38개와 동적으로 회전하는 문 박스를 사용한다. 플레이어는 반경 0.31 m 원기둥으로 판정하고 X/Z 축을 나누어 벽을 따라 미끄러진다. 이동을 최대 0.08 m씩 나눠 낮은 프레임에서도 얇은 벽을 통과하지 않도록 한다. 바닥과 머리보다 높은 문 상인방은 이동을 막지 않는다. 무거운 물리 엔진은 사용하지 않는다.

`DOOR_Main`, `DOOR_ServerRoom`, `DOOR_RecordsRoom`은 경첩 위치에 Pivot이 있는 독립 부모 오브젝트다. 닫힘 0°, 열림은 입구 100°와 내부 문 95°다. Blender Z축이 GLB에서 Y축으로 바뀐다. 0.45초 보간 중에도 문 충돌을 매 프레임 갱신하며 플레이어가 회전 범위에 있으면 닫힘을 멈추고 다시 연다. 판정 경계의 5 mm 여유는 문 앞에 붙었을 때 열림이 막히는 수치 오차를 피한다.

## 로딩·성능·보안

모델 로딩은 진행 표시, 20초 제한, 재시도, 2D 이어하기를 제공한다. 픽셀 비율은 최대 1.5, 그림자는 단일 1024 맵이며 주요 장비만 그림자를 만든다. 고정 환경은 재질별로 묶어 렌더 호출을 줄이고 도구 창이 열려 있는 동안 3D 렌더링을 멈춘다. 숨겨진 탭에서는 이동과 렌더링을 중단한다.

Three.js 0.186.1과 필요한 GLTFLoader·PointerLockControls·유틸리티를 `vendor/three`에 포함한다. Python 및 개발 서버는 이름이 정확히 허용 목록에 있는 파일만 제공한다. 실제 파일 경로가 게임 폴더 안에 있는지도 확인한다. GLB MIME은 `model/gltf-binary`다. CSP는 self 스크립트·스타일과 정확한 SHA-256으로 승인한 기존 시작 복구 스크립트만 허용한다. `unsafe-inline`과 `unsafe-eval`은 허용하지 않는다. connect/image의 blob 허용은 GLB 내부 텍스처를 브라우저에서 디코딩하기 위한 것이며 외부 URL 접속을 허용하지 않는다.

## 검증과 한계

`npm ci`, `npm run check`, `tests/windows_launcher.ps1`를 실행한다. 기존 테스트는 `?view=2d`로 모든 원래 동작을 계속 검증한다. 새로운 테스트는 실제 WASD 이동, 마우스, 달리기, 크기 변경, 닫힌 문 충돌, 경첩 회전, 문 닫힘 보호, 장비 5종까지 걸어가는 경로, 도구 창에서 전체 미션 완료, 저장 복원, CSP, 모델 요청 실패·제한 시간, 가져오기 대화상자의 Esc·Tab, 3D 도구 창에서 다른 탭의 최신 저장 보호를 검사한다. 3D 이동은 데스크톱 Chromium에서 검증하고 Firefox·WebKit은 기존 2D 도구와 선택한 2D 보기를 검사한다. 라이브 카메라를 직접 옮기는 테스트용 텔레포트 API는 없다.

60 FPS는 일반 GPU 사용 시의 목표이며 모든 학교 PC에서 보장한 수치가 아니다. 하드웨어 가속이 꺼진 소프트웨어 렌더러는 느릴 수 있으므로 2D 보기로 전환할 수 있다. 현재 이동은 평탄한 실내 보행이며 점프·계단 물리·임의 지형 걷기는 범위에 포함되지 않는다. 실제 모바일 기기, Firefox·Safari, 스크린리더 전체 경험은 추가 검증이 필요하다.

## 패키징

`python -m pip install pyinstaller==6.20.0` 후 `python scripts/package.py`를 실행한다. 결과는 `dist/SecurityLab.exe`다. 내장 Python/Tk, 원래 앱, 새 모듈, GLB, Three.js 및 라이선스를 포함한다. 제작용 Blender나 원본 JPG는 실행에 필요 없고 EXE의 공개 리소스에도 포함하지 않는다.

`python scripts/export_web.py`는 같은 공개 리소스를 웹 ZIP으로 만든다. 로컬 개발 브랜치에서 제작한 결과이며 별도 GitHub 릴리즈 게시까지 수행한 것은 아니다.
