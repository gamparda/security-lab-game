Security Lab v0.2.2 · Windows 10/11 64비트용 포터블 로컬 웹앱입니다.

이번 버전에는 다음 변경을 포함합니다.

- EXE는 내장 서버가 모든 게임 파일을 정상 제공하는지 확인한 뒤 브라우저를 엽니다.
- CSS 적용과 게임 모듈 초기화·저장된 진행 복원이 완료될 때까지 로딩 안내를 표시합니다.
- CSS 로딩 실패는 한 번 자동 재시도하고, 로딩 실패나 시간 초과 시 다시 불러오기를 안내합니다. 정상 저장은 유지합니다.

- `SecurityLab-Windows-x64.zip`을 압축 해제하고 `SecurityLab.exe`를 더블클릭하면 기본 브라우저에서 게임이 열립니다.
- Python·Node.js·npm 설치와 관리자 권한이 필요 없습니다.
- 실행 창의 「게임 다시 열기」와 「종료」 버튼으로 조작합니다. 플레이하는 동안 실행 창을 유지하세요.
- 튜토리얼과 필수 미션 3개, 힌트·학습 점수·브라우저 저장·초기화를 포함합니다.
- 진행은 브라우저에 저장되어 실행 파일을 다른 PC로 옮겨도 함께 이동하지 않습니다.
- `security-lab-web.zip`은 나중에 홈서버에 올릴 정적 웹 파일입니다. HTTPS 설정 후 제공해야 SHA-256 계산이 가능합니다. 현재 홈서버에는 배포하지 않았습니다.
- 배포 절차에서 패키징된 실행 파일을 사용한 엔진·서버·PC/모바일 브라우저 테스트와 Windows 실행 창 시작 검증을 수행합니다. 모든 검사가 성공한 패키지만 게시합니다. 자동 실행 창 검증에서는 브라우저 자동 열기를 생략하고 창 표시·로컬 서버 응답·전체 게임 파일 준비 완료를 확인합니다.

파일 무결성 기준은 `SHA256SUMS.txt`에 포함합니다. 이 게임은 가상 보안 교육용이며 실제 서버를 스캔하거나 실제 로그인 공격을 실행하지 않습니다.
