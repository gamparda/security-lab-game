Security Lab v0.2.3 · Windows 10/11 64비트용 포터블 로컬 웹앱입니다.

- 서버의 게임 파일 확인은 최대 30초 동안 재시도합니다. 느린 첫 실행의 단일 2초 제한으로 앱이 시작되지 않던 경로를 수정했습니다.
- 확인 중에도 실행창을 조작할 수 있고, 실패 시 「준비 다시 시도」 버튼으로 재검사할 수 있습니다.
- 게임 모듈 준비는 최대 30초 기다리고, 요청 실패는 페이지를 한 번 자동으로 다시 열어 복구합니다. 저장된 진행은 유지합니다.
- CSS 적용과 게임 초기화·진행 복원이 완료된 뒤에만 게임 화면을 표시합니다.
- Windows ZIP은 `SecurityLab.exe` 하나만 포함합니다. 웹 ZIP과 ZIP 내부 가이드는 기존 릴리즈에서도 제거합니다.

`SecurityLab-Windows-x64.zip`을 압축 해제하고 `SecurityLab.exe`를 실행하세요. Python·Node.js·npm 설치와 관리자 권한은 필요 없습니다. 플레이하는 동안 실행창을 열어두고, 업데이트 전에는 이전 실행창을 종료하세요.

진행은 같은 주소·포트의 브라우저에 저장되며 실행 파일과 함께 다른 PC로 옮겨지지 않습니다. 튜토리얼과 필수 미션 3개, 힌트·학습 점수·초기화를 포함합니다. 가상 보안 교육용이며 실제 서버 조사나 로그인 공격을 수행하지 않습니다.

패키징된 EXE의 엔진·서버·PC/모바일 브라우저 검사와 Windows 실행창 검증을 모두 통과한 패키지만 게시합니다. 자동 실행창 검증에서는 브라우저 자동 열기를 생략합니다. 파일 무결성 기준은 `SHA256SUMS.txt`에 포함합니다.
