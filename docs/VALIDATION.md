## v0.3.0 로컬 검증 · 2026-10-04

Windows 11 / Python 3.13.14 / Node 24.18.0 / Blender 5.2.2 LTS / Chromium 153에서 검증했다. `npm ci`, `npm run check` 통과. 3D의 키보드·마우스용 검사 5개는 모바일 프로젝트에서 제외했으며 모바일 2D 시작 검사는 통과했다. EXE만 복사한 한글·공백 임시 경로에서 실제 실행창, 공개 리소스 전부, 두 인스턴스의 독립 포트 및 같은 브라우저 검사 59개가 통과했다.

1920 × 1080, RTX 5060 Ti / D3D11 하드웨어 가속으로 실습실 중앙에서 60 FPS를 관측했다. 이 측정은 해당 PC의 대표 시점 관측값이며 모든 학교 PC의 최저 프레임을 보장하지 않는다. 기본 headless 소프트웨어 렌더러 SwiftShader는 약 7–11 FPS였으므로 Windows 검증은 실제 GPU를 사용하도록 구성했다.
