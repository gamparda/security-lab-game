# 검증

## 실행

```sh
npm run check
```

시스템 Chromium: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run check`.

## 게시 버전

| 버전 | 엔진 | 서버·배포 | 브라우저 | Windows 실행창 |
| --- | ---: | ---: | ---: | --- |
| v0.2.0 | 32 | 4 | 24 | 통과 |
| v0.2.2 | 32 | 6 | 42 | 통과 |
| v0.2.4 | 32 | 12 | 46 | 통과 |
| v0.2.5 | 32 | 14 | 46 | 통과 |
| v0.2.6 | 32 | 10 | 48 | 통과 |

전체 플레이, 정상 기능 유지, 저장·초기화, 해시 복원 실패, 키보드 조작, 입력 처리, 로딩 실패·재시도, 동시 파일 요청을 검사합니다.

Windows 배포 검사는 EXE만 있는 임시 폴더에서 실제 실행창을 시작하고, 내장 파일·별도 인스턴스 포트·PC/모바일 게임을 확인합니다.

## 미확인

v0.2.6 실행은 사용자 PC에서도 확인했습니다. 실제 모바일·Firefox·Safari·스크린리더와 교육 효과·플레이 시간은 검증하지 않았습니다.
