## 알려진 한계와 수동 검증 계획

- 첫 프로토타입이며 학습 분량과 난이도를 사용자 시연으로 다듬어야 합니다.
- 30–45분의 목표 플레이 시간과 교육 효과는 아직 검증하지 않았습니다.
- 시뮬레이션은 실제 HTTP·방화벽·인증 시스템의 세부 동작을 구현하지 않습니다.
- 로그인 정책의 길이 15·3회 제한은 이 게임에서 선택한 예시입니다. 실제 서비스의 모든 인증 구성에 일률 적용하는 권고가 아닙니다.
- localStorage는 같은 브라우저의 진행 정보이며 서버 동기화·공정한 점수 인증을 제공하지 않습니다.
- 내장 오프라인 기준을 신뢰하는 게임 상황입니다. 실제 파일 서명·기준 배포·키 관리는 구현하지 않았습니다.
- 기준값과 현재 해시는 실제 바이트에서 계산합니다. 개인 파일 업로드 기능은 없습니다.
- 스크린리더 및 실기기 수동 검증, 입문자 3–5명 시연은 후속 작업입니다.

수동 시연에서는 포트 전체 차단의 실패 이유와 해시 일치의 의미를 플레이어가 자신의 말로 설명하는지 기록합니다. 시연 체크리스트와 후속 우선순위는 `ROADMAP.md`를 참고합니다.
